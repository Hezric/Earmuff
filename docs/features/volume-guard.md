# Volume protection

Earmuff watches the Windows default render endpoint (`eConsole`) through Core Audio device and endpoint-volume notifications. Audio writes are serialized on one COM worker behind `AudioBackend`. For a protected output, a rounded full-volume reading (99.5% or higher, matching the prior tool's rounding) drops to the configured drop level; other readings above the cap clamp to the cap. Unprotected outputs receive no writes. Pausing stops writes for the saved duration (60 minutes by default, 1–720 whole minutes) using a monotonic deadline; resume enforces immediately. Restarting resumes protection.

Settings use `%APPDATA%\Earmuff\Earmuff.ini`, with defaults defined in `src-tauri/src/settings.rs`. Device sections use hex-encoded stable endpoint IDs. New outputs are protected. Software and display outputs stay under Other devices even after use as the default; expanding the group exposes the same individual protection switches as the main list. Classification uses Windows device ancestry and endpoint form factor rather than friendly-name matches. Software audio under `ROOT` and display audio fold into Other devices. Physical USB speakers stay in the main list. If classification metadata is unavailable, leave the output in the main list with protection on.

Malformed settings activate safe defaults and show an error without silently overwriting the original file during discovery. User edits write a replacement through a synced temporary file. Save and audio errors are visible in the flyout and tray tooltip.

The resident app owns a notification worker and tray icon, with no initial webview or login registration. The shared [Linen shell](https://github.com/Hezric/Linen/blob/v0.1.1/docs/features/tray-shell.md) owns placement, native DWM styling, motion and dismissal. Its UI package supplies the shell, current card, pause presets, language and about controls. The flyout begins directly with the current card. Settings retain the protection sliders and saved custom pause duration. Enter or focus loss saves valid input; invalid input preserves the saved duration and displays an error. Editing duration preserves an active pause deadline. English and Simplified Chinese follow Windows unless explicitly selected.

A round check badge on the headphones means the current output is protected; plain headphones mean it is unprotected or absent, and a round pause badge indicates a pause. All states use full-contrast taskbar ink. App state and audio writes stay here; shared shell changes are made in Linen. Inter and shared UI assets come from the tagged UI package; Chinese subsets are generated from application and shared strings.

`vp run dev` is a browser-only mock preview and never accesses Windows audio. `vp run test` checks the browser model. `cargo test --manifest-path src-tauri/Cargo.toml --locked` uses simulated audio. The ignored `audio::tests::enumerate_only` test reads endpoint metadata only; running it explicitly never reads or writes volume or starts the app. Real notification latency, tray placement, live taskbar changes, and webview release require an authorized native session.
